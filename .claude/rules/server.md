# Правила серверного кода

- Публичные выборки идут только через `publicTitleWhere()` / `publicEpisodeWhere()`.
  Прямой `prisma.title.findMany({})` в публичном роуте — баг: он покажет
  черновики и скрытые тайтлы.
- Каждый server action начинается с проверки сессии и роли. До валидации входа,
  до всего остального.
- Всё, что пришло извне (форма, вебхук, query), проходит через zod-схему.
  Тип из `await request.json()` — это `any`, ему нельзя верить.
- Вебхуки проверяют подпись до разбора тела.
- Секреты читаются в серверном модуле и не попадают в пропсы клиентских
  компонентов. Перед коммитом проверь, что новый env не утёк в бандл.
- Ошибки внешних сервисов не глотаем: логируем с контекстом и возвращаем
  понятный статус. Пустой `catch {}` запрещён.
- В воркере любая сетевая операция имеет таймаут и лимит попыток.
  `FLOOD_WAIT` от телеграма — это «подожди столько-то», а не провал задачи.
- Миграции генерируются Prisma и не редактируются руками. Деструктивную
  миграцию (drop колонки) выноси в отдельный PR с пометкой в описании.
