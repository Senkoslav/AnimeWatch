# Правила фронтенда

- Server Component по умолчанию. `"use client"` добавляется на минимально
  возможный лист дерева, а не на страницу целиком.
- Цвета только через токены из `docs/04-design-system.md`. Хардкод hex в
  компоненте — повод остановиться и добавить токен, если его не хватает.
- Шрифты подключаются через `next/font`, не ссылками на Google Fonts.
- У каждого `<Image>` заданы `width`/`height` или `fill` с контейнером
  фиксированного соотношения. Постеры всегда 2:3.
- Скролл-анимаций, параллакса и ховер-эффектов на каждой карточке не делаем.
  Причина в дизайн-доке, раздел «Движение».
- Состояние фильтров и вкладок живёт в URL (`searchParams`), не в `useState`.
  Ссылка должна открываться в том же виде в другой вкладке.
- Любой интерактивный элемент доступен с клавиатуры и имеет видимый фокус.
- Мобильная вёрстка проверяется на 360px до того, как задача считается сделанной.
- localStorage — только для настроек устройства (громкость, качество,
  отключённые подсказки). Данные пользователя — в БД.
