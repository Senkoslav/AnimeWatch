# AnimeWatch

Каталог аниме с плеером: метаданные свои, видео — фреймом от поставщика
(Kodik). Ближайшая цель — живой сайт под заявку на доступ к их базе.

```
CLAUDE.md                     ← подхватывается автоматически каждую сессию
docs/01-product-brief.md      ← кто пользователь и что в scope
docs/02-architecture.md       ← стек, маршруты, кеш, безопасность
docs/03-data-model.md         ← prisma-схема и правила работы с ней
docs/04-design-system.md      ← токены, типографика, что запрещено
docs/05-kodik.md              ← доступ к Kodik, фрейм плеера, что неизвестно
docs/06-roadmap.md            ← задачи с критериями приёмки, рабочий файл
docs/07-testing.md            ← что тестируем и чего не тестируем
.claude/rules/*.md            ← правила, подгружаются по маске файлов
.claude/skills/ui-review/     ← /ui-review, проверка экрана перед сдачей
.claude/agents/reviewer.md    ← ревью дифа в отдельном контексте
.claude/settings.json         ← форматирование и typecheck по хукам
```

## Локальный запуск

```bash
nvm use                 # Node 24: на 25.x не работает Vitest
pnpm install
cp .env.example .env.local   # заполнить DATABASE_URL и DIRECT_URL
createdb animewatch
pnpm db:deploy          # применить миграции
pnpm db:seed            # демо-данные
pnpm dev
```

Для тестов на базе нужна отдельная база с суффиксом `_test`:
`createdb animewatch_test`, дальше `pnpm test:db` сам применит миграции.

## Порядок работы

1. Задача берётся из `docs/06-roadmap.md`: «возьми следующую невыполненную
   задачу из роадмапа, покажи план».
2. После каждой задачи, где менялся интерфейс: `/ui-review`.
3. Перед коммитом: `pnpm verify` и субагент `reviewer` по дифу.

## Что править по ходу

Роадмап — живой файл, отмечай сделанное там же. Дизайн-док и модель данных —
источник правды: если реальность разошлась с ними, чинится док, а не память.

## Заполнить до заявки в Kodik

- Домен (свой выглядит серьёзнее `vercel.app`)
- Контактный адрес для `/dmca` и юридических страниц
- Проверка `/terms` и `/privacy`: они написаны по фактическому поведению сайта,
  но не юристом
