# AnimeWatch

Каталог аниме с плеером: метаданные свои (импорт с Shikimori), видео — фреймом
поставщика (Kodik). Живой сайт: https://animewatch-gamma.vercel.app

Заявка на доступ к базе Kodik отправлена 2026-09-24 (`docs/05-kodik.md`). Пока
её рассматривают, страницы просмотра честно говорят «источник не подключён», а
интеграция готовится на моках — чтобы после выдачи токена серии заиграли одной
переменной.

## Что есть на сайте

- Главная: промо последней серии, новые серии, онгоинги, популярное, расписание
- Каталог с отбором (жанр, год, статус, тип), сортировкой и поиском по названию
- Поиск, устойчивый к опечаткам (`pg_trgm`): страница `/search` и окно по Ctrl+K / ⌘K
- Страница тайтла и страница просмотра с сеткой серий
- Вход через Google, свои списки («смотрю», «брошено»…) и оценки 1–10, профиль со статистикой
- `/schedule`, `/random`, `/dmca` с формой обращения, `/terms`, `/privacy`
- SEO: canonical, Open Graph, `robots.txt`, `sitemap.xml`; знак и иконки

## Локальный запуск

```bash
nvm use                 # Node 24: на 25.x не работает Vitest
pnpm install
cp .env.example .env.local   # обязательны DATABASE_URL и DIRECT_URL
createdb animewatch
pnpm db:deploy          # применить миграции
pnpm db:seed            # демо-данные
pnpm dev
```

Остальное в `.env.example` необязательно, без него сайт работает и говорит, чего
не хватает: нет `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET` — окно входа пишет, что
вход подключается; нет `REDIS_URL` — лимиты запросов пропускают всё; нет
`KODIK_API_TOKEN` — плеера нет, страница просмотра об этом говорит.

Для тестов на базе нужна отдельная база с суффиксом `_test`:
`createdb animewatch_test`, дальше `pnpm test:db` сам применит миграции.

**Не запускайте `vercel env pull` в `.env.local`**: он перезапишет файл
переменными из Vercel, и локальный сайт уйдёт в облачную базу. Секретные
переменные (`REDIS_URL`, ключи Google) Vercel всё равно не отдаёт.

## Прод и превью

- Прод — Vercel, база — Neon, Redis — интеграция Vercel. Сборка идёт через
  `scripts/vercel-build.sh`: применяет миграции и не соберёт прод без
  `DMCA_IP_SALT`.
- Превью Vercel (любая ветка, кроме `main`) получает свою ветку базы Neon —
  копию боевых данных; миграции превью применяются только в неё (`docs/03`).
- Иконки и картинка превью ссылок собираются из `public/brand/mark.svg`:
  `node scripts/brand/render.mjs`.

## Порядок работы

1. Задача берётся из `docs/06-roadmap.md`: «возьми следующую невыполненную
   задачу из роадмапа, покажи план». Задачи нет в роадмапе — сначала её туда.
2. После каждой задачи, где менялся интерфейс: `/ui-review`.
3. Перед коммитом: `pnpm verify`, e2e по фиче и субагент `reviewer` по дифу.

## Что править по ходу

Роадмап — живой файл, отмечай сделанное там же. Дизайн-док и модель данных —
источник правды: если реальность разошлась с ними, чинится док, а не память.

## Открыто от владельца
