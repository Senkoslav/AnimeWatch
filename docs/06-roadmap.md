## Открытые вопросы

Найдены при разборе доков до первой строчки кода. Решаются в задаче, указанной
в скобках; решение записывается в соответствующий док, пункт отсюда удаляется.

- **Превью серии под токеном** (Ф2, вебхук). `thumbnail.jpg` из Bunny закрыт тем
  же CDN-токеном (без подписи 403), его URL нельзя просто положить в
  `Episode.thumbUrl`. Либо подписывать превью на сервере при рендере (и не
  кешировать страницу дольше токена), либо копировать кадр в своё хранилище.
  Пока герой главной без кадра показывает постер.
- **Постеры Shikimori мелкие** (Ф1, импорт Shikimori). `original` — 225×318, на
  телефоне с DPR 3 это мыло. Нужен другой источник постера или загрузка своего.
  Shikimori переехал на `shikimori.io`, старый `shikimori.one` отвечает 301.
- **База для превью Vercel** (Ф4, прод). Главная — ISR и рендерится на
  `next build`, так что сборка без `DATABASE_URL` падает. Превью нужна своя
  база (ветка Neon) с данными, иначе они либо не соберутся, либо увидят прод.
- **Cache Components** (Ф4, перед запуском). Каталог динамический и ходит в
  базу на каждый показ: без `cacheComponents` кешировать данные можно только
  устаревающим `unstable_cache`. Включение флага меняет модель кеша всего
  приложения (`export const revalidate` уходит, вместо него `use cache` и
  `cacheLife`) — отдельная задача с замером нагрузки на базу.
- **Скрытие по жалобе и выданные ссылки** (Ф1, админка). `HIDDEN` закрывает
  страницы и API сразу, но уже выданный подписанный URL играет до 2–4 часов.
  Действие «скрыть тайтл» в админке должно ещё отключать видео тайтла в Bunny
  (или менять ключ токенов в экстренном случае), см. `docs/05`, «Воспроизведение».
- **Вес страницы просмотра** (Ф4, перед запуском). 384 КБ JS gzip против ~177 КБ
  на остальных страницах: hls.js и UI Video.js. Для приёмки брифа «первый кадр
  < 2 с на 4G» замерить на превью; если не укладываемся — попробовать лёгкий
  `HlsVideo` Video.js или грузить hls.js только там, где нет нативного HLS.
- **Замер LCP** (Ф4, CI). Lighthouse в режиме `simulate` на `localhost` даёт
  LCP 3.3 с независимо от вёрстки: все запросы стартуют в первые 20 мс, и
  симуляция считает загрузку всего JS и шрифтов. `devtools`-троттлинг даёт 1.6 с.
  Приёмку по LCP мерить на превью Vercel (Lighthouse CI из `docs/07`).
- **Отложенная публикация** (Ф1, админка). `publicEpisodeWhere()` пропускает
  `publishedAt` в будущем: серия с датой «на завтра» видна сразу. Либо
  `lte: now` (спорит с ISR), либо запрет будущих дат в zod-схеме админки.
- **Недостающие env** (Ф1). Почтовый провайдер для формы DMCA, хранилище для
  загрузки постеров.
- **Временный источник `TELEGRAM`** (Ф2). Виджет поста встраивается только из
  публичного канала, а мастера лежат в приватном: такой источник не заработает.
- **Фильмы больше 4 ГБ** (Ф2). `MOVIE` при ~20 Мбит/с весит 13+ ГБ, лимит
  Premium на файл — 4 ГБ. Фильмам нужен прямой аплоад в Bunny мимо телеграма.
