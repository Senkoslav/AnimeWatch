## Открытые вопросы

Найдены при разборе доков до первой строчки кода. Решаются в задаче, указанной
в скобках; решение записывается в соответствующий док, пункт отсюда удаляется.

- **Черновик тайтла** (Ф1, Prisma). У `Title` нет `publishedAt`, статус по
  умолчанию `ONGOING`: недозаполненный тайтл виден сразу после создания.
  `HIDDEN` при этом смешивает «черновик» и «жалобу правообладателя».
- **`Bookmark.titleId` без relation** (Ф1, Prisma). Нет внешнего ключа: закладки
  остаются сиротами после удаления тайтла, `include: { title }` не работает.
- **Версия Prisma** (Ф1, Prisma). Схема в `docs/03` написана под Prisma ≤6:
  `url` в `datasource` и `prisma-client-js`. В Prisma 7 это изменилось, а
  `latest` в npm на 2026-09-16 указывает на `8.0.0-rc.15` (последняя стабильная
  — 7.10.0): выбрать версию и сверить схему. Next, TypeScript и Node решены, см. `docs/02`, «Версии».
- **Недостающие env** (Ф1). `DIRECT_URL` для миграций в обход pooler, почтовый
  провайдер для формы DMCA, хранилище для загрузки постеров.
- **Временный источник `TELEGRAM`** (Ф2). Виджет поста встраивается только из
  публичного канала, а мастера лежат в приватном: такой источник не заработает.
- **Фильмы больше 4 ГБ** (Ф2). `MOVIE` при ~20 Мбит/с весит 13+ ГБ, лимит
  Premium на файл — 4 ГБ. Фильмам нужен прямой аплоад в Bunny мимо телеграма.
- **Токен протухает на паузе** (Ф3, плеер). Срок «длина серии с запасом» не
  спасает от долгой паузы: плеер должен перевыпускать URL по 403.
- **Vidstack и Video.js 10** (Ф3, плеер). Vidstack вливается в Video.js 10;
  перед выбором плеера проверить, какая библиотека сейчас развивается.
