# 04. Дизайн-система

Здесь не просто токены, а объяснение, почему выбрано именно это. Если
предлагаешь изменение — объясняй так же. Главная претензия, от которой уходим:
«выглядит ии-шно».

## Откуда взят визуальный язык

Палитра пришла из прошлой версии проекта, где она была оправдана метафорой
студии звукозаписи. Метафора ушла вместе со студией, палитра осталась — и
основание у неё теперь другое, более прямое.

Сайт смотрят вечером и в темноте, с телефона, ради одного действия: включить
серию. Значит интерфейс тёмный и приглушённый, а единственный акцент помечает
то, что происходит прямо сейчас: серия, которую смотришь, новый выпуск,
заполненная часть полосы воспроизведения.

Постеры аниме сами по себе кричащие и разноцветные. Интерфейс не соревнуется с
ними за внимание: цвет на странице приносят постеры, а не наши блоки.

## Токены

```css
--bg:        #0E1116;  /* холодный графит, не «почти чёрный» */
--surface:   #151A21;  /* карточки, панели */
--surface-2: #1D242D;  /* ховер, активная строка */
--line:      #28313C;  /* границы; толщина всегда 1px */
--text:      #E7EBF0;
--muted:     #8E9AA9;  /* вторичный текст, не ниже 4.5:1 на --bg */
--signal:    #FFB02E;  /* единственный акцент: то, что происходит сейчас */
--signal-dim:#7A5512;  /* тот же акцент под текстом/полосой прогресса */
--danger:    #E5484D;  /* только ошибки, больше нигде */
```

Акцент — янтарный, и он **не декоративный**. Им красится только то, что
происходит прямо сейчас: серия, которую смотришь; новый выпуск; заполненная
часть полосы воспроизведения. Если янтарный появился в блоке, где ничего не
происходит, — это ошибка.

Радиусы: `4px` мелкие элементы, `8px` карточки и постеры, `999px` только у
аватаров. Больше ничего.

Теней нет. Глубина — через `--surface` и `--line`. Тень допустима одна:
выпадающие меню плеера.

## Типографика

| Роль | Гарнитура | Назначение |
|---|---|---|
| Дисплей | **Unbounded** 600/700 | логотип, номер серии, заголовок героя |
| Текст | **Golos Text** 400/500/600 | всё остальное |

Обе с полноценной кириллицей. Inter не используем — это шрифт по умолчанию у
всего, что сгенерировано, и он читается как отсутствие выбора.

Шкала: 12 / 14 / 16 / 20 / 28 / 40 / 64. Межстрочный — 1.5 для текста, 1.1 для
дисплейных размеров. Длина строки описания — до 70 символов.

Запрещено:
- ALL CAPS для подписей и «eyebrow»-лейблов над заголовками
- выделение одного слова в заголовке цветом или курсивом
- моноширинный шрифт для мелких подписей «под данные»
- стрелка `→` в конце текста ссылок и кнопок
- цепочки через `·` вида «2024 · TV · 12 эпизодов» (ставь нормальные разделители
  и группируй по смыслу)

## Макеты

Главная. Герой — последний выпуск: кадр из серии (или постер, если кадра нет),
поверх номер серии крупно. Не слайдер: слайдеры на мобильном никто не листает.

```
┌───────────────────────────────────────────┐
│ ЛОГО      каталог                      ⌕ │
├───────────────────────────────────────────┤
│  [ кадр из последней серии, 16:9 ]        │
│   Название тайтла                          │
│   ЭПИЗОД 07   вышел 2 часа назад           │
│   ( Смотреть )                             │
├───────────────────────────────────────────┤
│  Свежее                                    │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐              │
│  │пост│ │пост│ │пост│ │пост│   2:3, 8px   │
│  └────┘ └────┘ └────┘ └────┘              │
└───────────────────────────────────────────┘
```

Страница тайтла. Постер слева липнет при скролле, справа — содержание и серии.
На мобильном постер уходит в шапку, список серий — основной блок экрана.

```
┌──────────┬────────────────────────────────┐
│ [постер] │ Название                        │
│  2:3     │ 2024, TV, 12 серий, онгоинг     │
│          │ жанры                            │
│ (Смотреть)│ описание, 3 строки + «ещё»     │
│          ├────────────────────────────────│
│          │ Серии                           │
│          │ ▸ 01 ···················· 24:10 │
│          │ ▸ 02 ──────·············· 24:10 │ ← полоса прогресса
│          │ ▸ 03  новая                     │
└──────────┴────────────────────────────────┘
```

Просмотр. Фрейм плеера во всю ширину контентной колонки, 16:9, список серий
справа на десктопе и под плеером на мобильном. Никаких боковых панелей с
рекомендациями: человек пришёл смотреть. Внутри фрейма — плеер поставщика, наши
токены на него не действуют, и это нормально: снаружи от него всё наше.

## Движение

Своего плеера у нас нет, поэтому движения на сайте нет вообще. Единственное, что
двигается, — контролы внутри фрейма поставщика, и это не наша зона.

Не делаем: `fade-in-up` у секций при скролле, анимацию каждой карточки при
наведении, параллакс, счётчики цифр. Это самый узнаваемый признак
сгенерированной страницы.

`prefers-reduced-motion` отключает всё, что мы могли бы анимировать.

## Текст в интерфейсе

Кнопка называет действие и не меняет имя по дороге: «Смотреть» ведёт к плееру,
«Сохранить» даёт тост «Сохранено». Пустые состояния зовут к действию, а не
извиняются: «Здесь появятся серии, которые вы начали смотреть» + ссылка в
каталог. Ошибки говорят, что произошло и что делать: «Источник для этой серии ещё не
подключён» вместо «Ошибка загрузки».

## Порог качества

Каждый экран перед сдачей:

- работает на 360px без горизонтального скролла
- фокус виден с клавиатуры на всех интерактивных элементах
- контраст текста ≥ 4.5:1, крупного ≥ 3:1
- у изображений заданы размеры, чтобы не прыгала вёрстка
- тач-цели не меньше 44×44

## Что было отброшено и почему

Первый набросок был предсказуемым: тёмно-фиолетовый фон, градиент в герое,
неоново-розовый акцент, стеклянные карточки. Это дефолт для всего, что связано с
аниме, и ровно то, что заказчик назвал «ии-шным». Заменено на графит + одиночный
янтарь, работающий как индикация состояния.

Второй отброшенный вариант — «почти чёрный фон + кислотный зелёный». Выглядит
современно и встречается в каждом втором сгенерированном интерфейсе.

Если тебе кажется, что странице не хватает яркости, — добавь контента, а не
цвета. Яркость на этом сайте приносят постеры.
