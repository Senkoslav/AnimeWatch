# 04. Дизайн-система

Здесь не просто токены, а объяснение, почему выбрано именно это. Если
предлагаешь изменение — объясняй так же. Главная претензия, от которой уходим:
«выглядит ии-шно».

Макеты этого документа живут на дизайн-холсте (ссылка у владельца): четырнадцать
артбордов на 1440 и на 390. Холст — картинка, этот файл — источник правды.
Расходятся — прав этот файл.

## Что здесь произошло

Мир третий по счёту, и он закрывает спор двух предыдущих.

1. **Графит и янтарь.** Первая редакция этого дока: холодный тёмный фон,
   единственный янтарный акцент на том, что происходит сейчас.
2. **«Вкладыш».** Ветка `feat/redesign-insert` увела код в тёплый печатный
   картон с зелёной офсетной краской и линованными трек-листами. Доку под неё
   не переписали, и полгода файл врал про код.
3. **«Ночное стекло».** Возвращаем графит и янтарь — у них было основание, — а
   от «Вкладыша» оставляем то, что действительно работало: линованные списки,
   номер слева, хронометраж справа, нарисованное пустое место. Сверху
   добавляется один новый материал — стекло, и у него есть закон (ниже).

Зелёная краска и сплошные полосы разделов (`components/ui/band.tsx`) уходят.

## Откуда взят визуальный язык

Сайт смотрят вечером и в темноте, с телефона, ради одного действия: включить
серию. Значит интерфейс тёмный и приглушённый, а единственный акцент помечает
то, что происходит прямо сейчас: серия, которую смотришь, новый выпуск,
активный фильтр, заполненная часть полосы.

Постеры аниме сами по себе кричащие и разноцветные. Интерфейс не соревнуется с
ними за внимание: цвет на странице приносят постеры, а не наши блоки.

## Токены

Готовый блок для `app/globals.css`. Стандартные палитра, радиусы, тени,
размытие и шрифты Tailwind по-прежнему сброшены в `initial`: в разметке
доступно только то, что описано здесь.

```css
@theme {
  --color-*: initial;

  /* Холодный графит, чуть глубже прежнего: на нём читается стекло. */
  --color-bg: #0b0e13;
  --color-surface: #14181f;   /* панели, карточки, списки — плотная поверхность */
  --color-surface-2: #1a1f28; /* ховер, активная строка без краски */
  --color-line: #ffffff1a;    /* границы, всегда 1px */
  --color-text: #edf1f7;
  --color-text-2: #c9d2dd;    /* абзацы на поверхности */
  --color-muted: #99a4b4;     /* вторичный текст, 7.6:1 на bg */
  --color-dim: #8a94a4;       /* подписи 11–12px, 6.3:1 на bg */

  /*
   * Сигнал. Один, янтарный. Закон: означает «сейчас» — свежая серия, играющая
   * строка, активный фильтр, оценка, заполненная часть полосы. Появился там,
   * где ничего не происходит, — это ошибка.
   */
  --color-signal: #ffb02e;
  --color-signal-ink: #17110a; /* текст на янтарной заливке, 11:1 */
  --color-signal-soft: #ffb02e24; /* заливка активного состояния, 14% */
  --color-signal-line: #ffb02e57; /* граница активного состояния, 34% */
  --color-signal-muted: #efd49d; /* вторичный текст на янтаре: тон от янтаря, не серый */
  /* Фон ::selection. Янтарь под текстом, а не сам янтарь: soft — это 14%, на выделении его
     не видно, а полный сигнал забрал бы себе смысл «сейчас». */
  --color-signal-deep: #4a3410;

  --color-danger: #ff6b6b; /* только ошибки формы */

  /* Светлая плёнка вторичных кнопок, чипов и пилюль навигации. Не стекло: она ничего не
     размывает, а лишь поднимает элемент над поверхностью — и работает поверх стекла тоже. */
  --color-fill: #ffffff12;
  --color-fill-2: #ffffff1f; /* она же под курсором */

  /* Стекло: три уровня и ни одним больше (см. «Стекло»). */
  --color-glass-chrome: #0e1219b8; /* 72% */
  --color-glass-panel: #ffffff0e;  /* 5.5% */
  --color-glass-modal: #161b23db;  /* 86% */

  /* Палитра диаграмм: см. «Диаграммы». Не акцент бренда, меняется только набором. */
  --color-chart-watching: #c98500;
  --color-chart-planned: #3987e5;
  --color-chart-completed: #199e70;
  --color-chart-dropped: #d95926;

  --radius-*: initial;
  --radius-sm: 10px;   /* поля, мелкие кнопки, чипы */
  --radius-md: 14px;   /* карточки, крупные кнопки */
  --radius-lg: 20px;   /* постеры, плеер, панели */
  --radius-xl: 26px;   /* модалка и нижний лист */
  --radius-full: 999px; /* только аватары */

  --shadow-*: initial;
  --shadow-modal: 0 40px 100px #0000009e; /* единственная тень в системе */
  --drop-shadow-*: initial;
  --inset-shadow-*: initial;
  --text-shadow-*: initial;

  --container-page: 86rem;  /* ширина страницы с артбордов: 1376 при 1440, поля 16/32 */
  --spacing-sticky: 4.5rem; /* высота липкой шапки плюс отступ */
  --spacing-rail: 3.5rem;   /* поле номера в линованных списках */

  --text-*: initial;
  --text-xs: 0.75rem;   --text-xs--line-height: 1.5;
  --text-sm: 0.8125rem; --text-sm--line-height: 1.55;
  --text-base: 0.875rem; --text-base--line-height: 1.6;
  --text-md: 0.9375rem; --text-md--line-height: 1.6;
  --text-lg: 1.0625rem; --text-lg--line-height: 1.35;
  --text-xl: 1.25rem;   --text-xl--line-height: 1.2;
  --text-2xl: 1.75rem;  --text-2xl--line-height: 1.1;
  --text-3xl: 2.5rem;   --text-3xl--line-height: 1.05;
  --text-4xl: 2.75rem;  --text-4xl--line-height: 1.04;

  --animate-*: initial;
}
```

Контрасты посчитаны и проверять их заново не нужно: `muted` 7.6:1, `dim` 6.3:1,
`signal` 10.4:1 — всё на `--color-bg`. На янтарной заливке вторичный текст
берётся **тоном от янтаря** (`#efd49d`), а не серым: серый на цветной плашке —
отдельный признак сгенерированного интерфейса.

## Стекло

Материал, которого в проекте раньше не было. Его закон: **стекло размывает то,
что под ним реально есть.** Слой над изображением, над прокрученной страницей,
над выдачей — стекло. Панель на пустом фоне — плотная поверхность
(`--color-surface`), потому что размывать ей нечего, и это уже украшение.

| Уровень | Где | Рецепт |
|---|---|---|
| 1. Хром | липкая шапка, нижняя панель на телефоне, строка статуса под плеером | `bg-glass-chrome` + `backdrop-blur(20px) saturate(140%)` + `border-b border-line` |
| 2. Панель | значки на постерах, блок «вышло сегодня» поверх героя | `bg-glass-panel` + `blur(18px) saturate(140%)` + `border-line` + `inset 0 1px 0 #ffffff17` |
| 3. Модалка | вход, нижний лист фильтров, меню профиля, подсказка на диаграмме | `bg-glass-modal` + `blur(34px) saturate(160%)` + `border #ffffff24` + `shadow-modal` |

Значок поверх постера — случай второго уровня с оговоркой: постеры заранее неизвестны, и белая
плёнка в 5.5% над ярким кадром не даёт тексту никакого контраста. Материал остаётся вторым
(размытие 18, волосяной блик), но основа под ним тёмная (`bg` 65%). Порог контраста здесь
старше таблицы.

Обязательные сбросы, без них стекло выпускать нельзя:

```css
@supports not (backdrop-filter: blur(1px)) {
  .glass { background: var(--color-surface); }
}
@media (prefers-reduced-transparency: reduce) {
  .glass { background: var(--color-surface); backdrop-filter: none; }
}
```

Плотная поверхность — это `--color-surface` с границей `--color-line`. Панель
отбора, карточка оценки, списки серий, блоки профиля, лента комментариев стоят
именно на ней.

## Знак

Лигатура AW (решение владельца 2026-09-24 из пяти эскизов): правая нога A
становится первым штрихом W — одна ломаная линия. Перекладина A — янтарь, и это
единственный сигнал логотипа, поэтому прежняя янтарная точка после слова ушла.
Геометрия строгая: штрихи одной толщины (10 из 100), концы срезаны горизонтально
по линии букв, как у шрифта, острая только средняя вершина W. Перекладина
ниже середины и толще штриха: выше она пропадала между ногами уже в 24 px.

- Исходник — `public/brand/mark.svg`. Иконки (вкладка, телефон, манифест) и
  картинку превью ссылок собирает `node scripts/brand/render.mjs`; цвета скрипт
  берёт из токенов `app/globals.css`.
- В разметке знак — `components/site/logo-mark.tsx`: буквы `currentColor`,
  перекладина `fill-signal`. Hex знака живёт только в файлах иконок.
- Иконка вкладки — знак на плитке `surface`: одинаково читается на светлой и
  тёмной вкладке.

## Типографика

| Роль | Гарнитура | Назначение |
|---|---|---|
| Дисплей | **Unbounded** 600/700 | логотип, заголовки страниц и разделов, номер серии, числа в статистике |
| Текст | **Golos Text** 400/500/600 | всё остальное |

Обе с полноценной кириллицей и обе проверены по списку переиспользованных
гарнитур из `impeccable`: Inter, Roboto, Montserrat, Geist, Space Grotesk,
Plus Jakarta Sans, Instrument — там, наших нет. Inter не используем отдельным
пунктом: это шрифт по умолчанию у всего, что сгенерировано.

Шкала: 11 / 12 / 13 / 14 / 15 / 17 / 20 / 28 / 40 / 44. Межстрочный 1.5–1.6 для
текста, 1.05–1.15 для дисплейных. Трекинг дисплейных −0.03em, пол −0.04em.
Длина строки абзаца 65–75 символов.

Запрещено:
- ALL CAPS для подписей и «eyebrow»-лейблов над заголовками
- **надзаголовок (кикер) над заголовком вообще** — заголовок несёт себя сам
- нумерация разделов 01 / 02 / 03, если последовательность не несёт информации
- выделение одного слова в заголовке цветом или курсивом
- градиент в тексте: выделение идёт весом или размером
- моноширинный шрифт как костюм «технологичности»
- стрелка `→` в конце текста ссылок и кнопок
- цепочки через `·` вида «2024 · TV · 12 эпизодов»

## Поверхности браузера

То, что мы не рисовали, всё равно принадлежит дизайну. Задаётся один раз в
`@layer base` и дальше не обсуждается: `::selection`, `caret-color`,
`scrollbar-color`, кольцо `:focus-visible` (2px янтаря, отступ 2px),
`text-underline-offset`, `::placeholder`, табличные цифры у `time`, `output` и
`[data-numeric]`. Это самый дешёвый признак того, что страницу сделали, а не
собрали, и его пропускают чаще всего.

## Компоненты

- **Кнопка главного действия** — янтарная заливка, текст `--color-signal-ink`,
  высота 48–54, радиус `md`. Вторичная — прозрачная с границей `--color-line` на
  `#ffffff12`. Третичная — только текст `--color-muted`.
- **Чип** — высота 32–36 (на телефоне 44), радиус `sm`. Активный: заливка
  `signal-soft`, граница `signal-line`, текст янтарный.
- **Поле и `<select>`** — высота 44–48, радиус `sm`, фон `#0b0e1399`, граница
  `--color-line`, размер текста 16px на телефоне (iOS иначе увеличивает
  страницу).
- **Карточка каталога** — постер 2:3 радиус `md`, значок оценки стеклом в левом
  верхнем углу, название в две строки фиксированной высоты, под линейкой
  выходные данные и статус.
- **Заголовок раздела** — засечка 3×18 плюс заголовок Unbounded. Засечка
  янтарная там, где раздел про «сейчас» (новые серии, онгоинги, расписание),
  и нейтральная в остальных. Сплошных залитых полос больше нет.
- **Линованная строка** (`.row-ruled`) — из «Вкладыша» остаётся как есть: номер
  в фиксированном поле слева, содержимое по центру, хронометраж справа. На ней
  держатся списки серий, расписание и статистика профиля.
- **Кнопка списков** («В список») — вторичная, пока тайтл ни в одном списке;
  с выбранным списком — `selected`: заливка `signal-soft`, граница `signal-line`,
  текст янтарный, на кнопке название списка. Меню — стекло третьего уровня:
  четыре списка переключателями и «Убрать из списка». У анонима та же кнопка
  открывает окно входа.
- **Своя оценка** — десять кнопок-переключателей 1–10 цифрами Unbounded: на
  телефоне две строки по пять (тач-цель 44), на широком экране одна. Выбранная —
  как активный чип. Стоит под оценкой Shikimori, и они не смешиваются.
- **Значок списка на постере** — стекло второго уровня на тёмной основе, как
  значок оценки, в правом верхнем углу; только показывает, ставится отметка на
  странице тайтла.
- **Пустое место рисуется** — прочерк и отточие вместо пробела. Выцветание
  запрещено: прозрачный текст не проходит по контрасту.

## Диаграммы

Появились вместе с профилем. Правила отдельные от интерфейсных.

- Палитра диаграмм **не зависит от акцента бренда**: четыре опознаваемых цвета в
  фиксированном порядке — `#c98500` смотрю, `#3987e5` запланировано,
  `#199e70` просмотрено, `#d95926` брошено. Набор проверен на тёмной
  поверхности по светлоте, цветности, контрасту и разделимости при протанопии,
  дейтеранопии и тританопии. Менять по одному цвету нельзя: проверяется набор
  целиком.
- Цвет никогда не единственный носитель смысла: рядом с кольцом всегда таблица
  с числами и долями.
- Кольцо — только часть от целого и не больше шести секторов, зазор между
  секторами 2px. Распределение оценок — столбцы одного тона со скруглением 4px
  сверху, подпись только у пикового столбца, средняя показана линией.
- Ряд крупных чисел с подписями («сколько просмотрено / часов / средняя») как
  шапка страницы не делается: это шаблон, который видно издалека. Цифры живут в
  линованном списке.

## Движение

Своего плеера у нас нет, и движения на сайте почти нет. Единственный авторский
момент — появление модалки и нижнего листа: 180 мс, затухающее ускорение, из уже
видимого состояния.

Не делаем: `fade-in-up` у секций при скролле, увеличение карточки при наведении,
параллакс, счётчики цифр, пружинное затухание (`bounce`). Это самые узнаваемые
признаки сгенерированной страницы.

`prefers-reduced-motion` отключает и этот единственный момент.

## Текст в интерфейсе

Кнопка называет действие и не меняет имя по дороге: «Смотреть» ведёт к плееру,
«Сохранить» даёт тост «Сохранено». Пустые состояния зовут к действию, а не
извиняются: «Здесь появятся серии, которые вы начали смотреть» плюс ссылка в
каталог. Ошибки говорят, что произошло и что делать: «Источник для этой серии
ещё не подключён» вместо «Ошибка загрузки».

## Порог качества

Каждый экран перед сдачей:

- работает на 360px без горизонтального скролла
- фокус виден с клавиатуры на всех интерактивных элементах
- контраст текста ≥ 4.5:1, крупного ≥ 3:1
- у изображений заданы размеры, чтобы не прыгала вёрстка
- тач-цели не меньше 44×44
- axe без critical и serious
- состояния нарисованы все: наведение, выключено, загрузка, ошибка, пусто
- фильтры, мобильное меню и вход работают без JS

## Что отброшено и почему

- **Тёмно-фиолетовый фон, градиент в герое, неоново-розовый акцент, стеклянные
  карточки везде.** Дефолт категории и ровно то, что заказчик назвал «ии-шным».
- **Почти чёрный фон плюс кислотный зелёный.** Встречается в каждом втором
  сгенерированном интерфейсе.
- **Зелёная офсетная краска «Вкладыша».** Работала как приём, но требовала
  тёплого картона под собой, а тёплый фон проигрывает постерам: они на нём
  выцветают.
- **Стекло на всех панелях.** Оставлено там, где под слоем есть изображение.
  В остальных местах это украшение, а не материал.

Если кажется, что странице не хватает яркости, — добавь контента, а не цвета.
Яркость на этом сайте приносят постеры.
