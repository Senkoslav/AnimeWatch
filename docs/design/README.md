# Макеты «Ночного стекла»

Исходники артбордов с дизайн-холста, по одному файлу на экран. Лежат здесь,
чтобы вёрстка бралась из точных значений, а не с глаза по картинке: у каждого
элемента в разметке стоят реальные отступы, радиусы, цвета и размеры текста.

**Это не страницы сайта и не запускаются сами.** Формат `.dc.html` — разметка
редактора холста: `{{дырки}}` подставляются из `renderVals()` в конце файла,
`<sc-for>` повторяет блок по списку, `<sc-if>` ветвится. Открывать их в
браузере бессмысленно, читать — да.

Порядок чтения при вёрстке экрана:

1. `docs/04-design-system.md` — токены и законы. Источник правды.
2. Нужный файл отсюда — точные значения и состояния.
3. Холст — общий вид и соседство блоков.

Постеры на макетах — плотные цветные заглушки: своих изображений у проекта нет,
а рисовать поддельные обложки нечестно. В вёрстке на их месте `components/ui/poster.tsx`.

Данные на макетах — образец, а не факты: названия настоящие, числа
правдоподобные. Единственное, чего на макетах нет намеренно, — счётчики лайков,
голосов и «смотрят сейчас»: своих пользователей у сайта пока ноль, и рисовать
их нельзя.
